01. 專案背景與願景

本專案旨在解決電商營運管理者面臨的高壓繁瑣工作環境。我們不只提供高效率的進銷存分析，更首度在商用後台中引入「每日靜心卡牌」與「流年靈數計算機」，協助創業家在面對複雜商業決策時，能保有一份沈穩與靈魂直覺。

02. 全端技術架構

架構基於輕量高效之核心理念，後端使用穩定的 API 傳輸，確保商品數據、訂單狀態與占卜運算皆能在 100ms 內極速運算。前端利用精細計算的微光漸層與磨砂玻璃卡片佈局，擺脫以往後台系統乾癟死板之氣息。

03. 資料庫結構設計

為了支撐複雜的靈性功能，資料庫除了儲存一般的商品表與訂單表，更設計了符合十二宮與塔羅對應的關聯型關聯結構，完美確保所有流年、占卜預測數據讀寫皆滿足安全隔離規範。

04. 靈性美學之交織

將「暮色占卜與晨曦草本」的色彩代碼與 UI 層級結合。系統的每一處 hover 動效、分隔線與卡牌呼吸發光，都是對使用者心靈頻率的溫和撫慰，讓每一次系統使用皆成一場自我覺察。
